# Section 3 independent source review

Reviewed `references/obligations/3.json` against the live Apple App Review Guidelines Business section and the ignored private source catalog on 2026-09-26. All 127 private Section 3 source fragments have public `req-*` counterparts. This report contains no source quotations. The 90 empty obligation routes are expected pending Wave 2 and are not counted as source classification defects.

## Findings

1. **High — Binding conditions are hidden as exceptions.** Several `atom-*` records express a condition that an app must satisfy when invoking a payment allowance, but have `kind: exception`. This removes them from the obligation denominator and future attestation routing. Split the allowance from its mandatory condition, or make the condition an obligation with a clear link to the allowance. Affected examples: `atom-54c9e12357d247e6a0e41c048bd5d3dc` (3.1.3(b), matching in-app purchase), `atom-85bddc7ff5734633a258029655074c9b` (3.1.4, in-app purchase alternative), `atom-5b8921dd8dc94abd992bd4b024718aee` (3.1.5(i), organization enrollment), `atom-0d521530026845aa8ea7b9e7295b3283` (3.1.5(iii), exchange approval and local licensing), and the scope conditions in 3.1.3(a), (c), (d), (f), (g). Preserve the permission itself as an exception when splitting.
2. **High — Free companion exception has incorrect Boolean meaning.** `atom-2ddcf75d3e544bb6828e52f95a702bb4` (3.1.3(f)) says a companion qualifies when it sells nothing **or** lacks external checkout promotion. The source requires both restrictions. Change the condition to require no in-app purchase and no off-app purchase prompt, and retain the free stand-alone companion predicate.
3. **High — Several current routes do not inspect the stated obligation.** `atom-8dd8832bc69041b1983ac64bd888fd5b` maps charity Apple Pay availability to `applepay-recurring-disclosure`, which only detects recurring payment disclosure. `atom-6f16c5183f3d41f49c43bfc5e9c7c210` maps loan terms to `subscription-disclosure`. `atom-d697d85363f54565ae5c0054ad8d7205` maps minimum subscription period to `autorenew-disclosure`, which only inspects a localization key. `atom-96e8caaddd2c4a07b1083d241c64c59e` maps App Store Connect trial setup to `trial-disclosure`, which scans source wording. `atom-2c72981d6d74406da156c61e391c2dc7` maps the zero-price nonconsumable product requirement to the same wording scan. `atom-a5cc1d35bc12484e97df04d10d240d9d` maps entitlement-related fraud to `misleading-marketing`, which targets unrelated product claims. `atom-7d481d3a56db42dc9ff64dc3581315e1` and `atom-21321b0580604d559a3ee1d04814f3e9` map actual continuing value and tier transitions to a disclosure-only semantic question. Remove these route edges or implement evidence targeted to each criterion; the existing checks cannot decide even a useful partial result for these conditions.
4. **Medium — Storefront exceptions are not linked to their prohibitions.** The US exception `req-38283652f1c14cb7981d3a040eeb1294` has no `exceptions` inbound link from `atom-a017a6446edb434fb697a7a183abec0a`, while its criterion depends on that carve-out. The music entitlement `atom-14ae5df863d948a2bba1f3eaddd03398` is linked to that general prohibition but not to the base IAP rule `atom-997058a40b3344e99d8bdee763e77f8b`; check whether the latter needs a separate exception link or whether the entitlement only permits an external prompt. Link the US carve-out to every affected prompt prohibition after resolving its platform scope. Also scope `req-95650ef4819840ca891f87b367c802cc` to Mac App Store distribution rather than `all_apple_platforms`.
5. **Medium — Hardware exception narrows the source.** `atom-4ca70616c9714b4888be2a7ef99c08eb` (3.1.4) says the feature must depend on a connected device. The source allows dependence on specific hardware; a physical connection is not itself a condition. Reword the criterion and applicability around hardware necessary to the feature.
6. **Medium — Outside-service exception is broadened.** `atom-9d89f302b4884abe85a3c33aafe22ed2` (3.2.2(vii)) accepts the other service's unspecified permission. Its linked exception correctly names that service's terms. Require the terms-based allowance in the obligation criterion as well.
7. **Medium — Loan disclosure criterion can miss terms.** `atom-6f16c5183f3d41f49c43bfc5e9c7c210` (3.2.2(ix)) asks only for prominent, understandable conditions, and its sibling names APR and due date. The source requires the complete set of applicable loan terms to be disclosed. Make completeness explicit so a partial offer is not treated as compliant.
8. **Low — A few named scopes should be explicit.** `atom-903a6bd06d5d494995c4aad1f0d38e87` (3.1.5(iv)) does not expressly identify initial coin offerings, though it names crypto securities and futures. `atom-b61a39c81a9b47b6a300b3dc1a9b8a14` (3.2.2(viii)) prohibits providing binary-options trading while the source covers facilitating it through an app. Expand those criteria to include the stated cases.

## Review boundary

The public file preserves every private source fragment ID and generally splits compound duties into traceable atoms. This review does not treat mere implementation gaps as classification errors. Recheck the affected IDs after edits, then run the copyright boundary and coverage tests.
