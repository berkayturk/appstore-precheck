# Artifact stream integration notes

- Merge `skills/appstore-precheck/references/registry/artifact.json` into the shared `check-registry.json`. It supplies nine `artifact-*` checks, each with implementation, symbol, test, line prefix, route, and evidence class.
- Add `tests/test-artifact-review.sh` to `tests/all.sh`. It runs without Apple tooling using command shims; `tests/local/artifact-review-macos.sh /absolute/path/to/App.app` is an optional real-artifact smoke test.
- Wire the opt-in artifact route in `scan.sh` using `bash skills/appstore-precheck/scripts/artifact-review.sh --app PATH --format json`. When no built artifact exists, call it without `--app` to obtain nine `NOT_RUN` records. It never launches app code. Do not count `ARTIFACT-*` lines in the existing verdict arithmetic.
- Obligation route candidates: entitlement/Info consistency (2.5.1, 2.5.4, 5.1.1), required-reason APIs (5.1.1/5.1.2), private APIs (2.5.1), ATS and URL schemes (2.5.1), SDK/minimum OS (2.5.x), embedded SDK privacy/signature (5.1.2), executable download/loading (2.5.2), debug artifacts (2.1). Associate only where the obligation's criterion matches the check's limited evidence.
- Document in `SKILL.md`/README: `.app`, `.ipa`, and `.xcarchive` inspection is opt-in and read-only. `nm`, `otool`, and `codesign` need Apple Command Line Tools. Unavailable tools produce `SKIP`; absent artifact produces `NOT_RUN`. SDK currency, static symbol attribution, suspicious schemes, ATS exceptions, embedded manifests, and loading strings require human review. The `artifact-sdk` check intentionally does not hardcode Apple's current SDK requirement.
- The artifact checker reads `Info.plist`, `PrivacyInfo.xcprivacy`, Mach-O linkage/symbols, signatures, entitlements, and filenames. Its `PASS` values are scoped observations, never overall App Store approval. IPA members are extracted only into a temporary directory with path and size guards. No files are written under the supplied app or project.
